# Beranda (Home) — Task Breakdown

Source: Figma/screenshot "Beranda". Presentation = design; behavior/API = PRD + API contract.
Feature folder: `lib/features/home/` (existing placeholder `HomePage`).

## Cross-cutting decisions

- **One provider per section**, scoped with `ChangeNotifierProvider` in `HomePage`
  (sections load independently → one failing section must not blank the screen).
- Each section = `*_section.dart` (stateless, props only) in
  `features/home/presentation/widgets/`; `HomeView` only composes them.
- Data crosses features by repository, not by importing another feature's provider.
  `farm`, `activity`, `notification`, `weather` repositories are created in their own
  feature and reused here.
- **API contract has no home endpoints documented** (`doc/architecture/api_convention.md`
  only shows `GET /farms`). Every endpoint below is marked `TBD` → confirm with backend
  before T-x.2. Don't invent fields.
- Every section: loading (skeleton/shimmer-less placeholder), empty, error + retry, success.
- Pull-to-refresh on the page reloads all section providers.
- Tokens only (`AppColors/AppSpacing/AppTypography`). New recurring values (card radius 20,
  card shadow, green-tint chip colors, orange "belum" chip) → add to `core/theme` once.
